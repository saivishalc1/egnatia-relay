Ten-minute checklist

  • Server is up. In a terminal from the project folder run npm start if it is not. Browser tab open at http://localhost:3001, signed in with change-me.
  • You land on Agents → Opportunities. Leave it there. Press Esc to close any open drawer.
  • Browser zoom at 110%. The left rail badge reads Follow-ups 9. If it reads anything else, reseed (right).
  • Do not press Process new on Inbox or Generate memo before the call. Both are the payoff moments.
  • Copy the walkthrough notes from screen 06 into a scratch note so you can paste them in one go.
  • Have the roadmap answers from screen 09 in your head: texts, audio transcription, calendar, DOB lookups.
Reset to exactly this script

To go live, in order

  • Private GitHub repo, deploy the Dockerfile to Railway or Render with a persistent volume at /data.
  • Set APP_URL, a real APP_PASSWORD, and AUTO_SEED=false so it starts empty.
  • Add ANTHROPIC_API_KEY. Every draft, memo, and filing switches to Claude.
  • Google Cloud OAuth client, Gmail and Calendar APIs enabled, then Settings → Connect Gmail as info@egnatiaconstruction.com.
  • Enter the real agents with tiers. First nightly run at 6:00 the next morning.

Roadmap, if they ask what's next

  • Texts via Twilio for agents like Daniel who don't do email.
  • Audio upload and transcription for walkthrough voice notes.
  • Calendar events for walkthroughs; DOB NOW status lookups by BIN.
  • Postgres and per-client instances when there's more than one contractor on the platform.
